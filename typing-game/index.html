우리 반 단어장
① 단어장 자동 생성
단원을 누르면 아래 단어장에 단어가 채워져요. 여러 단원을 누르면 합쳐집니다.
② 단어 다듬기 · 직접 추가
뜻 보고 치기: 단어=뜻 형식으로 넣으면 학생 화면에 뜻과 초성 힌트만 보여요. (예: 광합성=식물이 빛으로 양분을 만드는 일)
단어를 자유롭게 추가하거나 지울 수 있어요. 띄어쓰기가 있는 문장은 보스 전투 문장이 됩니다. (예: 식물은 빛으로 양분을 만든다)
[단어장 저장]은 이 컴퓨터·이 브라우저에만 저장돼요. 저장한 단어장은 ①의 검색에도 나타납니다.
링크가 복사되었어요! 학생들에게 보내면, 열자마자 이 단어장으로 게임할 수 있어요.
③ 우리 반 전체에 배포 (관리자)
배포 목록을 정리한 뒤 배포 파일 내려받기를 누르면 class-wordsets.js 파일이 저장돼요.
GitHub 저장소 → Add file → Upload files로 이 파일을 올려 덮어쓰면, 1~2분 뒤 모든 학생의 시작 화면에 우리 반 단어장으로 나타납니다.
